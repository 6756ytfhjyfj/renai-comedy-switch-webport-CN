# 平行恋爱喜剧 · 汉化网页版

这是一部完整游戏的浏览器移植版，包含原资源包中的男女主角路线、分支剧情、附加内容、人物资料、CG、音乐与视频。

## 游玩

打开网站，点击「点击进入游戏」开启声音，再选择「开始游戏」「读取存档」或「附加内容」。手机请横屏使用。画面按原来的 1280 × 720 等比缩放，超宽屏幕会留边；不会为了填满屏幕而拉伸或裁切画面。

左上角的工具菜单提供游戏菜单、全屏、声音和存档备份。浏览器支持全屏时可以尝试锁定横屏；若浏览器没有提供全屏接口，可旋转手机或添加到主屏幕。

进度保存在当前浏览器和当前网站地址中。清除网站数据、使用隐私浏览或更换设备可能导致进度丢失。请用「导出存档」备份，在另一个设备上用「导入存档」恢复。原 Windows 存档文件没有被修改，也不会自动上传到网站。

## 本地预览

需要 Node.js。双击 `启动本地预览.cmd`，再访问 http://127.0.0.1:8765/ 。需要通过 HTTP 服务打开；直接双击 HTML 不能正确加载剧情资源。

## GitHub Pages 发布

这是无需构建的静态网站。完整网站约 957 MB，每个文件均低于 100 MB。

1. 使用专用公开仓库 `6756ytfhjyfj/renai-comedy-switch-webport-CN`。
2. 上传此文件夹中的网站文件，包括 `.github/workflows/pages.yml`；不要上传原来的 Windows 安装文件和 `.sav` 存档。
3. 在仓库 Settings → Pages 中，将 Source 设为 GitHub Actions。
4. 工作流成功后，使用 Pages 页面返回的地址游玩。

完整网站资源保存在 GitHub 仓库中。后续修改提交到 `main` 后，GitHub Actions 会重新发布网站。

## 验证与原包限制

已在 Chromium 浏览器中验证 8 种手机、平板与桌面尺寸：保持 16:9、横竖屏切换、中文剧情、男女主角入口、附加内容、保存进度、刷新后读档、存档导入导出，以及全部 23 个 MP4 的媒体元数据加载。

尚未逐句通关全部剧情分支，也尚未使用实体 iPhone / Android 设备测试。

原资源包的 CG 画廊有 4 个引用没有对应图片。网页版只略过这 4 个失效帧，保留所有实际存在的图片与剧情，避免画廊卡在不存在的图片上。

游戏文本、汉化、人物、图像、音乐、视频及原版引擎属于原作者与相应权利人。网页移植保留原游戏的作者信息和附加内容。
